              Aide

              1. Créer un parcours

              • Sur le terrain : enregistre le départ, puis chaque poste en te tenant dessus, puis l'arrivée (ou « Arrivée = départ »).
              • À la fin, choisis le type de course : ordre imposé, ordre libre ou score (temps limité, points par poste modifiables dans la fiche du parcours).
              • Les parcours s'échangent en GPX (Partager / Importer), et ceux d'O'Guide sont compatibles.

              2. Courir

              • La carte montre tous les postes avec les symboles de course d'orientation ; le poste à chercher est entouré.
              • Un poste se valide tout seul quand on passe dessus (carillon et vibration) ; les temps par poste sont enregistrés.
              • Ta position n'est affichée que jusqu'au départ. En course seul, tu peux la garder affichée (avec ta trace) dans les Réglages ; en course organisée, c'est l'organisateur qui décide.
              • Aide facultative : bips d'approche de plus en plus rapides, distance et direction du poste le plus proche (Réglages).
              • GPS capricieux ? « Valider » (appui long) prend le poste à chercher le plus proche, signalé « manuel » dans les résultats.

              3. Organiser une course en direct

              • Fiche du parcours › 📡 Organiser : type de course, départ groupé ou individuel, position visible ou non, bips autorisés, rayon de validation.
              • Un code et un QR code s'affichent : les coureurs le scannent avec l'appareil photo ou tapent le code dans « Rejoindre une course ».
              • Le tableau de bord montre chaque coureur sur la carte (avec sa trace), ses postes, son temps, sa batterie, et signale qui est immobile ou sans nouvelles.
              • Départ groupé : « Lancer le départ » démarre tous les chronos. « Clore » arrête la course. Le classement s'exporte en CSV pour un tableur.
              • Tu peux quitter le tableau de bord et y revenir depuis l'accueil : rien n'est perdu.
              • ⏯ Replay : chaque coureur envoie sa trace complète ; le replay rejoue la course (vitesse ×10 à ×120, curseur de temps). Les traces restent sur ton appareil, même après avoir effacé la course du relais.

              Bon à savoir

              • Le suivi passe par internet (4G). Sans réseau, la course continue et les données partent dès le retour de la connexion.
              • Sur navigateur (iPhone notamment), garde l'écran allumé pendant la course pour que la position continue d'être envoyée.
              • Sur l'appli Android, le suivi continue téléphone verrouillé (notification « Shadow CO – GPS actif »).
              • Relais : les données passent par un service public gratuit, chiffrées avec le code de la course. Pense à « Effacer la course du relais » à la fin (menu ⋯).

              📍 Suivi d'entraînement

              • Pour l'enseignant ou l'entraîneur : « Suivi d'entraînement » sur l'accueil crée une séance sans parcours, avec un code et un QR code.
              • Les pratiquants rejoignent avec le code ou le QR code, puis rangent le téléphone : pas de carte, pas de balise, rien à faire. Le suivi reprend tout seul si l'appli redémarre.
              • Tu suis tout le monde sur la carte en direct : trace, distance, vitesse moyenne, batterie, alertes (immobile, sans nouvelles). Puis ⏯ Replay de la séance.
              • « ⏹ Terminer » arrête le suivi sur tous les téléphones. 📊 Bilan : tableau CSV (durée, distance, vitesse, allure) et traces GPX de tous les pratiquants, à ouvrir dans un logiciel d'analyse.
